# 持续学习第一版

本版本为离线交付；代码完成不代表已部署、策略已启用或真实模型效果已提升。
流程为关键交互／反馈 → 服务端任务经历 → 核验来源 → 合成开发案例 → 现有策略实验 → 管理员启用。
不自动修改模型权重、代码、权限、质量阈值、修复参数或显式个人记忆。

## 开关与使用

- `/admin/learning`：管理员按环境开启结构化采集、设置每日新增分析与核验调用数/token、控制近30天只读回填、查看聚合数据并审核合成开发案例。
- `/learning`：本人查看采集状态，分别开启新聊天分析和已核验任务历史参考，查看／撤销个人材料，确认偏好候选。
- 默认采集关闭、两项个人开关关闭、每日新增调用数和 token 均为0；策略实验预算独立，旧评测授权不会自动成为聊天分析授权。
- 助手回复、保存草稿和 Run 显示反馈控件；Jobs 的 Feedback 链接进入本人反馈页。评价为已解决／未解决／需要修改，原因采用固定分类。无评价保持未知。
- CLI `/learning` 查看状态；`/feedback turn|run|job|pipeline <id> resolved|unresolved|modify [reason]` 使用相同服务端校验和 revision，不执行或确认任务。
- 事件仅发送固定类型、控件标识、UUID 和对象引用。搜索完成、算子选择、提交、预览阻塞、保存／修改、确认／取消、结果打开均是弱观察；不上传搜索词、表单值、DOM 或 URL 查询串。

## 来源与隐私

`ai_tools/learning` 使用现有控制数据库的增量建表、事务锁及审计，未引入第二套执行或审计系统。
`dp_learning_*` 保存环境／个人设置、事件、任务经历、来源关联、反馈、分析、调用账本、游标、案例和版本关联。
现有 `dp_ai_turns` 新增可空的 `learning_input`、`learning_epoch`：仅在用户同意后记录经过现有脱敏器的输入，解决会话 UI 仅保留最近12条历史导致的后台漏读。学习分析记录保存轮次引用、范围和哈希，短引用与分析账本不向其他账号或管理员公开。
聊天输入随既有轮次保留规则清理；学习不延长其期限。事件明细30天清理，即使采集关闭也执行保留期清理。

保存 Pipeline 时，无共享策略也可用本人 `assistant_request_id` 建立来源。再次编辑继承来源，服务端比较不可变定义中的算子、顺序、输入、参数、审核及证据引用；标题变化不算纠错。
输入位置／身份不能与对话证明一致时不归因；不按时间接近程度猜测关系。Run 包含的 Job 不另记为执行实例。
独立手动 Job 在提交时保存版本化命令摘要、输入身份和执行环境收据；旧的无精确版本／无收据／无最终确认任务仅作统计。
只有白名单操作能形成结构化共享来源；原文、短引用、姓名、路径、数据集名称和历史参数不会传给共享生成器。

来源引用为 `{kind: learning_episode, source_id, revision, digest}`，兼容旧 `run_id` 引用。
消费时重新核对管理员权限、原账号输入／输出权限、输入身份、保存版本、命令和最终 Attempt。
撤销会阻止旧 `run_id` 路径重新引入同一个经历；关联案例和策略失效，活跃绑定暂停，已提交任务继续。

## 后台与预算

`data-platform-learning@<env>.service` 每五分钟处理一次，未启用时仅做保留期维护。
每轮读取最多200条历史任务和200条实时任务；历史窗口冻结在管理员发起时的近30天，持久游标可暂停／重启。
不扫描数据文件、不补造历史点击或聊天关联。历史回填采用 Job 的 DATETIME 完成时间；实时 Run 采集跟踪协调器的终态更新时间，并为旧 FLOAT 时间保留 256 秒边界余量，兼顾舍入误差和延迟确认。独立 Job 使用 DATETIME 完成时间，来源键去重。暂停历史回填不会停止实时采集。
聊天按账号／会话分批，每批最多10轮、16000字符，长轮次保留字符游标；只读完成轮次。

模型只有无工具的受限提取和独立核验两次调用。枚举标签、精确引用和输出字段均由代码验证。
调用前按请求 UTF-8 字节上界加输出上限预留 token，持久写入未知状态后才触及模型接口。
成功返回记录实际用量；格式错误也计入已知用量，未知结果保守占用预留预算且不自动重发。
预算不足保持待处理；已完成提取可在预算补足后只执行核验，不重复提取。预算按 UTC 日期累计，管理页明确显示保留额度、实际报告用量和未知调用数。
租约、设置 revision、聊天授权 epoch 与来源哈希共同约束发布；关闭聊天立即阻止后续读取及发布。

个人扩展历史使用经过确定性核验的结构化事实，接入现有 experience 上下文和请求恢复摘要校验。
不伪造 AssistantFollowup，不向 Hindsight 新增付费留存／反思请求。已有 Hindsight 功能保持原有开关及处理范围。
偏好候选仅支持语言、简洁／详细说明，必须由用户确认后通过原 memory 接口保存；不会学习业务参数默认值。

## 离线改进与门禁

开发案例草案从已核验经历匹配固定合成场景，参数来自合成案例，不能来自实际业务任务。
没有安全匹配的经历继续保留结构化观察；管理员核验预期行为后才可导入开发集。
Strategies 导入评测集时保留已审核学习案例的来源依赖；诊断案例不能通过改 ID 或描述重新作为隐藏题。
本次没有创建新隐藏验收集；公开案例只作为回归。

候选生成复用受限模板、候选去重、服务端模板绑定、成对交错评测和分层开发门禁。
每日最多一次自动实验、至少10个不同有效执行实例的门槛包含独立 Job，并排除实验执行账号、重复 Pipeline Job、聊天、点击和反馈。
生成、评测、合成执行和管理员启用仍由原 Strategies 流程负责。没有改善时保留旧策略；不得自动启用。

看板的采集覆盖率使用近30天最新100个 Run 和100个独立 Job 中有权访问的有效对象作分母，并排除 Pipeline 内 Job。核验比例、实质修改率、反馈覆盖率另用最近200条／30天已采集经历样本与分母；不宣称是全部使用量覆盖。
无分母显示未知，执行失败、取消和基础设施故障分别统计；规划正确率仍以独立成对策略评测报告为准。

## 验收与发布

新增回归使用 SQLite、临时 socket-only MySQL、模型替身和临时合成数据。
具体结果、证明范围和发布状态见[离线验收记录](data_platform_continuous_learning_acceptance.md)。
运行 `DATA_PLATFORM_BROWSER_EXECUTABLE=/usr/bin/google-chrome .venv/bin/python experiments/assistant_langgraph/run_acceptance.py --learning` 可单独重验 MySQL 学习链。
`--runtime` 继续验证完整 MySQL/LangGraph、个人记忆和策略集成。
浏览器测试覆盖采集开关、个人授权和反馈；CLI 保留 TLS、登录、CSRF、确认及结果链接行为。

Server：新增学习 worker、表和可空轮次字段；旧客户端确认接口兼容。
Agent：不新增协议或自动执行能力，普通节点配额和最终确认不变。
CLI：独立兼容版本含状态／反馈入口。部署时先完成 dev 验收，再按原审批流程推广；同步发布不可变 CLI 安装器／wheel／CA，安装与 TLS 验收后才推进 latest。
本次不部署生产、不启用策略、不启动新增收费调用；后续新模型预算必须单独授权。
